## 新功能
- RAG 文档详情按 UTF-8 字节分页加载，避免大文档一次性进入 WebView。
- RAG 分片详情按页加载，并在滚动到底部时继续读取。
- RAG 增加可选的原始文件定时检查和自动重新索引，默认关闭。
- RAG 设置支持自动更新间隔和文档详情分页大小。

## 修复
- DynamicForm 拒绝 `__proto__`、`constructor` 和 `prototype` 路径，避免动态字段污染对象原型。
- 前端、Tauri 命令和 REST-to-IPC 映射补齐 RAG 分页接口。

## 兼容性
- 保留桌面端现有数据库迁移、HTTP 服务停止等待、按需启动、MCP 连接池、OpenAPI、Bearer Key 和 macOS ARM 稳定性修复。
- 自动更新默认关闭，不会因升级自动扫描本地文档；需要时可在 RAG 设置中手动开启。
